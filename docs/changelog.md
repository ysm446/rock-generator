# 変更履歴

## 未リリース

- なし

## 0.4.21 - 2026-05-03

- ノード接続をSDF評価に反映し、Crack Fieldをバイパスした場合に最終メッシュへ割れ処理が残らないようにしました。
- ノード入力は新しいリンク作成時に既存リンクを置き換えるようにし、CPU/GPUプレビューとRaymarch Previewも同じ接続順で評価するようにしました。

## 0.4.20 - 2026-05-03

- ノード座標の復元を `.rockproj` の `nodePositions` 優先に整理し、ロード後の初回ノード描画時に座標を適用するようにしました。
- node-editorの自動設定ファイルを無効化し、プロジェクトごとのノード座標と競合しないようにしました。
- ノード内の区切り線がキャンバス方向へ伸びないよう、固定幅の区切り線へ変更しました。

## 0.4.19 - 2026-05-03

- 「ファイル > 新規」を有効化し、デフォルトグラフ、ノード位置、ビューポート、プロジェクト状態を新規状態へ戻せるようにしました。

## 0.4.18 - 2026-05-03

- ノードネットワークのパン操作をマウス中ボタンドラッグに割り当てました。

## 0.4.17 - 2026-05-03

- 右側のノードネットワークとインスペクターを固定親カラム内に収め、プロパティウィンドウが押し出されないようにしました。

## 0.4.16 - 2026-05-03

- 右上ノードネットワーク向けにノード初期配置を横並びへ変更しました。
- ノードエディタ表示時に内容全体へ自動ナビゲートし、ノードがペイン外に出にくいようにしました。

## 0.4.15 - 2026-05-03

- メインレイアウトを左プレビュー、右上ノードネットワーク、右下インスペクター構成へ変更しました。
- プロパティ、統計、カメラ、計算、エクスポートを右下インスペクターのタブに集約しました。

## 0.4.14 - 2026-05-03

- GPU Preview経由でも `Voxels` 表示モードが反映されるよう、SDF readback後のプレビュー形状生成にOutput Mesh設定を渡すようにしました。

## 0.4.13 - 2026-05-03

- 表示メニューを `Mesh` / `Voxels` / `Raymarch` の直接トグルに変更しました。
- メッシュ表示モードをアプリ設定にも保存し、次回起動時に復帰するようにしました。

## 0.4.12 - 2026-05-03

- Output Meshノードに表示モード `Mesh / Voxels` を追加しました。
- 軽量なボクセル風プレビューを復活させ、プロジェクト保存/読込にも表示モードを含めるようにしました。

## 0.4.11 - 2026-05-03

- 最終メッシュ抽出をセル面ベースのボクセル風表示から、SDFゼロ交点を平均する簡易Surface Nets方式へ変更しました。
- ワイヤーフレーム表示がボクセル箱の集合ではなく、等値面に沿ったメッシュトポロジーを確認できるようにしました。

## 0.4.10 - 2026-05-03

- ウィンドウタイトルを `Mesh Generator <version>` 形式に変更しました。

## 0.4.9 - 2026-05-03

- SDF表面三角形から共有頂点、三角形インデックス、ユニークエッジ、頂点法線を持つMeshDataを生成するようにしました。
- メッシュプレビューとワイヤーフレーム表示をMeshDataのトポロジー参照に切り替えました。
- OBJエクスポートをインデックス付きメッシュと頂点法線を書き出す形式に更新しました。

## 0.4.8 - 2026-05-03

- Output Meshノードに解像度、LOD、Iso Value、Surface/Wireframe/Points/Sliceの表示設定を追加しました。
- Output Meshノードの設定を最終SDF評価とプロジェクト保存/読込に反映するようにしました。
- メッシュプレビューをOutput Meshノードの表示設定に従って描画するようにしました。

## 0.4.7 - 2026-05-03

- SDF Raymarch PreviewをD3D12 Compute Shaderで描画するようにしました。
- GPUレイマーチ結果をテクスチャへ書き込み、ImGuiビューポートに表示する経路を追加しました。
- GPUレイマーチが利用できない場合はCPUレイマーチプレビューへフォールバックするようにしました。

## 0.4.6 - 2026-05-03

- SDF Raymarch Previewのレイ生成を既存ビューポート投影に合わせ、メッシュ表示とスケールが揃うように修正しました。

## 0.4.5 - 2026-05-03

- CPUベースのSDF Raymarch Previewを追加し、「表示 > SDF Raymarch Preview」から切り替えられるようにしました。
- Raymarch PreviewとMesh Previewの表示状態を `data/app_settings.json` に保存するようにしました。

## 0.4.4 - 2026-05-03

- 最近使ったプロジェクトファイルを最大8件まで `data/app_settings.json` に保存するようにしました。
- 「ファイル > 最近使ったファイル」から履歴のプロジェクトを開けるようにしました。

## 0.4.3 - 2026-05-03

- UIテーマ、プレビュー計算バックエンド、ビューポートカメラ設定を `data/app_settings.json` に保存するようにしました。
- 次回起動時に保存済みのアプリ設定を読み込み、前回の作業環境へ復帰するようにしました。

## 0.4.2 - 2026-05-03

- 上部メニュー全体のパディングと項目間隔を調整し、文言が窮屈に見えないようにしました。

## 0.4.1 - 2026-05-03

- JSON形式の `.rockproj` プロジェクト保存/読込を追加しました。
- 保存対象にリンク、生成パラメータ、プレビュー段階、計算バックエンド、カメラ、UIテーマ、ノード位置を含めました。
- 「ファイル > 開く」「ファイル > 保存」「ファイル > 名前を付けて保存」を有効化しました。

## 0.4.0 - 2026-05-03

- GPU Preview バックエンドをD3D12 Compute Shaderに接続しました。
- GPUでプレビュー用SDF値を生成し、CPUへreadbackして既存の表面抽出と統計表示に反映するようにしました。
- 最終出力とOBJエクスポートは引き続きCPU計算を使う仕様を維持しました。

## 0.3.14 - 2026-05-03

- プレビュー計算バックエンドとして CPU / GPU Preview / Auto を選べる設定を追加しました。
- 右サイドバーに「計算」タブを追加し、要求バックエンドと実際に使われたバックエンドを確認できるようにしました。
- GPU はプレビュー専用とし、未接続の間は CPU にフォールバックする仕様にしました。

## 0.3.13 - 2026-05-03

- ビューポートの初期表示とリセット表示を、+Zを前面方向とする正面基準に変更しました。

## 0.3.12 - 2026-05-03
