# 変更履歴

## 未リリース

- なし

## 0.4.0 - 2026-05-03

- GPU Preview バックエンドをD3D12 Compute Shaderに接続しました。
- GPUでプレビュー用SDF値を生成し、CPUへreadbackして既存の表面抽出と統計表示に反映するようにしました。
- 最終出力とOBJエクスポートは引き続きCPU計算を使う仕様を維持しました。

## 0.3.14 - 2026-05-03

- プレビュー計算バックエンドとして CPU / GPU Preview / Auto を選べる設定を追加しました。
- 右サイドバーに「計算」タブを追加し、要求バックエンドと実際に使われたバックエンドを確認できるようにしました。
- GPU はプレビュー専用とし、未接続の間は CPU にフォールバックする仕様にしました。

## 0.3.13 - 2026-05-03

- ビューポートの初期表示とリセット表示を、+Zを前面方向とする正面基準に変更しました。

## 0.3.12 - 2026-05-03

- 床グリッドだけ別スケールで描かれていた問題を修正し、岩プレビューと周囲ボックスと同じワールドスケールに統一しました。

## 0.3.11 - 2026-05-03

- 岩プレビュー、周囲ボックス、ワイヤ表示の投影中心とスケールを統一しました。
- 周囲ボックスの奥側エッジを薄く、手前側エッジを濃く描き、パースに沿った見え方になるようにしました。

## 0.3.10 - 2026-05-03

- 右サイドバーに「カメラ」タブを追加しました。
- ビューポートの画角、距離、ズーム、Yaw/PitchをUIから調整できるようにしました。

## 0.3.9 - 2026-05-03

- ビューポートの上下オービット操作を反転しました。

## 0.3.8 - 2026-05-03

- ビューポートの左右オービット操作を反転しました。

## 0.3.7 - 2026-05-03

- ビューポートの投影を右手系カメラ基底に統一し、グリッド・プレビュー・軸ギズモが同じ座標変換を使うようにしました。
- 軸ギズモのX軸が反転して見える問題と、床グリッドが崩れて見える問題を修正しました。

## 0.3.6 - 2026-05-03

- Y-up表示に合わせて、ビューポートの上下オービット操作がDCCツールらしい向きになるように調整しました。

## 0.3.5 - 2026-05-03

- 中央ビューポートの背景を、右手系・Y軸上向きの3D床グリッドに変更しました。
- 10x10マス、1マス1メートルのグリッドと、左下のXYZ軸ギズモを追加しました。

## 0.3.4 - 2026-05-03

- プロパティタブに、選択中ノードに対応する項目だけを表示するようにしました。
- Output Mesh ノード選択時はビルドと OBJ エクスポート操作を表示するようにしました。

## 0.3.3 - 2026-05-03

- プロパティUIをラベル列と入力列に分け、文言の横にスライダーと数値入力が並ぶようにしました。

## 0.3.2 - 2026-05-03

- マウスホイールで固定レイアウトのパネルやビューポートが微妙に上下スクロールしないようにしました。

## 0.3.1 - 2026-05-03

- 上部メニューの項目間隔が詰まらないように、パネル用の余白調整をメニューバーへ影響させないようにしました。
- 現時点で不要な上部ボタン列を削除しました。

## 0.3.0 - 2026-05-03

- Road Editor に近い暗色テーマ `road_editor_dark` を追加し、標準テーマにしました。
- 上部モードバー、左右タブ付きサイドバー、中央ビューポート、下部ステータスバーの構成に変更しました。

## 0.2.1 - 2026-05-03

- パネル間の余白をなくし、ボーダーラインで区切るレイアウトに変更しました。
- パネル内の UI 要素には適度な余白を残し、操作部品同士が詰まりすぎないようにしました。

## 0.2.0 - 2026-05-03

- JSON 駆動の UI テーマ機構を追加しました。
- 上部メニューバーに「ファイル」「編集」「表示」「設定」「ビルド」「エクスポート」を追加しました。
- 「設定 > UIテーマ」から登録済みテーマを選択できるようにしました。
- 日本語メニュー表示のために Windows の日本語フォントを読み込むようにしました。
- パラメータのスライダー操作は、ドラッグを離したタイミングでプレビュー更新するようにしました。
